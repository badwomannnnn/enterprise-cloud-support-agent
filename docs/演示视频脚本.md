# 2 至 3 分钟演示视频脚本

## 0:00 至 0:20 项目背景

企业客户报告 API 故障时，经常缺少错误码、Request ID 和影响范围。这个 Agent 会先补齐信息，再检索文档、调用工具；证据不足时自动创建人工工单。

## 0:20 至 0:55 知识问答

在用户支持页面输入“API Key 应该放在哪里”。展示回答、引用文档和原文片段，强调系统没有根据常识自由发挥。

## 0:55 至 1:35 工具诊断

输入“返回 429，部分请求失败，Request ID 为 req-429-001，账户是 demo-account”。展开工具调用，展示错误码说明和模拟账户 QPS 已达到上限。说明查询结果明确标注演示环境。

## 1:35 至 2:05 人工升级

输入“生产环境刚刚所有请求 503，联系电话 13812345678”。展示手机号被脱敏、系统查询服务状态并创建 P1 工单。

## 2:05 至 2:30 工程师闭环

切换工程师工作台，将工单分派给二线支持，填写解决方案并标记为已解决。展示时间线和候选知识标记。

## 2:30 至 2:50 测试结果

展示测试报告和 42 条固定样例。说明指标由脚本生成，失败案例保留在报告中，没有为了简历虚构数据。
