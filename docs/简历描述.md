# 简历项目描述

## 项目名称

企业云产品智能支持与工单协同 Agent

## 技术栈

Python、FastAPI、Pydantic、SQLAlchemy、SQLite、LangGraph、Chroma、Streamlit、pytest、腾讯混元

## 描述模板

- 面向企业云产品咨询与 API 故障场景，设计“输入脱敏、意图分诊、信息追问、知识检索、工具诊断、人工升级”的 Agent 工作流，覆盖六类常见问题。
- 基于 FastAPI 和 SQLite 实现工单创建、分派、状态流转、处理时间线、用户反馈与候选知识标记；通过后端状态机阻止非法流转。
- 构建带来源元数据的虚拟产品知识库，并实现错误码精确匹配与离线检索；集成腾讯混元和 Mock 双模式，避免演示受网络或额度影响。
- 建立 42 条固定评测样例，使用脚本计算分类、Recall@3、工具选择、人工升级和脱敏指标；当前小规模离线测试集上各项自动检查均为 100%，并在报告中明确标注语料规模和本地延迟边界。

## 面试时的指标口径

不要只说“准确率 100%”，推荐完整表达：

> 在 42 条自建固定测试集上，意图分类、Recall@3、工具选择、升级判断和脱敏检查均达到 100%。这个结果主要用于验证流程正确性，因为语料规模较小且没有包含真实生产分布；真实模型回答的完整性和引用支持性仍需人工抽检。

这样的说法既能展示结果，也能说明你理解离线测试与生产效果之间的差异。
